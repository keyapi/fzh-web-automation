## 其他入库页 — 导入模板

### 打开导入弹窗

点击"添加单据"按钮 → 下拉菜单 → "导入入库单" → 弹窗出现。

### 导入弹窗结构

```
标题: "导入入库单"
按钮: [添加文件] [下载模板] [关闭] [导入]
注意事项:
  - 模板表头不可更改、不可删除
  - 支持 xlsx 格式

  - 以下组合重复时只取最后一条: 临时单号+入库仓库+SKU+店铺+FNSKU
```

## 其他出库页 — 导入模板

### 打开导入弹窗

点击"添加单据" → 用 JS 触发 el-dropdown 展开 → 点击"导入出库单" → 弹窗出现。
（注意：el-dropdown-menu__item 默认 `display:none`，需先展开后再点击）

```
标题: "导入出库单"
按钮: [添加文件] [下载模板] [关闭] [导入]
```

## 使用示例

```python
import pandas as pd

# 构造导入 Excel
columns = [
    "临时单号", "*入库仓库", "*入库类型", "运费（CNY）", "其他费用（CNY）",
    "费用分摊方式", "单位费用", "单据备注", "入库时间",
    "*SKU", "店铺", "FNSKU", "专属类型",
    "*采购单价(CNY)", "可用数", "次品数", "可用货架位", "次品货架位", "商品备注"
]
data = [
    "TEST-001",          # 临时单号
    "POLAND",            # *入库仓库
    "其他入库",           # *入库类型
    "",                  # 运费（CNY）
    "",                  # 其他费用（CNY）
    "", "", "",          # 分摊方式, 单位费用, 备注
    "",                  # 入库时间
    "test001-white",     # *SKU
    "", "", "",          # 店铺, FNSKU, 专属类型
    100.0,               # *采购单价(CNY) — 调整成本
    10,                  # 可用数 — 修改库存
    "", "", "", "",      # 次品数, 货架位, 商品备注
]
df = pd.DataFrame([data], columns=columns)
# ⚠️ Excel 需通过浏览器上传导入（页面有 CSRF header 保护）
```

## 踩坑

### 坑 1：导入入库后需手动确认
- **现象**：导入成功 (成功1条) 后库存未更新，导出文件找不到新增 SKU
- **原因**：导入后的入库单状态为"待确认"，库存不会自动生效
- **解决**：必须点击列表中的"确认入库"按钮，状态变为"已完成"后库存才更新
- **验证**：确认后再次导出，新增 SKU 出现在库存中

### 坑 2：菜单导航
- 顶部"仓库"必须点击 (#menu11)，hover 不行
- 子菜单中"其他入库"和"其他出库"是 `<A>` 标签，可通过 `a:has-text("其他入库")` 定位
- 不在仓库详情页的子菜单中，而是在顶部的仓库展开菜单里

## 与库存明细的关系（铁律）

**凡是修改库存的操作（其他入库/其他出库），必须先备份库存明细：**
1. 执行 `sellfox_auto_export.py` 导出当前库存
2. 进行入库/出库操作
3. 再次导出库存对比验证
