# 通途 — Excel 文件格式

> 库存结存清单（原始导出）和导入模板（生成文件）的格式详情。

---

## 原始清单（下载文件）

### 文件结构

```
行1: "库存结存清单"                            ← 标题行
行2: "仓库 CENTRADE  库存清单导出时间 2026-05-19" ← 仓库+时间
行3: (空行)
行4: SKU | 货品名称/规格 | ... (19列)          ← 表头
行5+: 数据行
末尾: 数量总计: xxx | ...                       ← 汇总行（跳过!）
末尾+1: 金额总计: xxx | ...                     ← 汇总行（跳过!）
```

### 列映射（19 列中关键的 3 列）

| Excel 列 | 位置 | 内容 | 导入模板目标列 |
|----------|------|------|---------------|
| A | 第 1 列 | SKU | SKU/SKU别名 |
| Q | 第 17 列 | 头程运费(CNY) | 头程运费 |
| S | 第 19 列 | 头程其它费(CNY) | 其他费用 |

> 注意：列位置可能因通途版本微调，代码中按列名匹配（`'头程运费' in col`）而非硬编码索引。

## 导入模板（生成文件）

### 格式规范

- **文件名**: `{仓库名}_通途导入_头程运费_其他费用.xlsx`
- **Sheet 名**: 任意（通途不校验）
- **5 列固定**:

| 列名 | 必填 | 说明 |
|------|------|------|
| SKU/SKU别名(必填) | ✅ | 库存清单中的 SKU |
| 安全库存 | ❌ 留空 | **必须留空(None)**，填 0 会覆盖通途现有数据！ |
| 头程报关费（CNY） | ❌ 留空 | **必须留空(None)**，填 0 会覆盖通途现有数据！ |
| 头程运费（CNY） | ✅ | 从库存清单 Q 列提取 |
| 其他费用（CNY） | ✅ | 从库存清单 S 列提取 |

### 关键陷阱

| 陷阱 | 说明 |
|------|------|
| **安全库存/头程报关费 = None** | 填 0 会覆盖通途现有安全库存和报关费数据 |
| **跳过汇总行** | Excel 末尾的"数量总计"/"金额总计"行必须排除 |
| **文件编码** | Windows GBK 不影响 XLSX 格式，无需处理 |
| **通途列位置可能变** | 不用硬编码列索引 Q/S，用 `'头程运费' in col` 匹配 |

## 合并文件（merge_inventory.py）

合并 6 个仓库的原始清单为一个大表，输出到 `output/`：

```
output/通途合并库存结存清单 {日期}.xlsx
```

合并逻辑：
1. 找每个文件的 SKU 表头行
2. 提取表头以下的数据行
3. 跳过"数量总计"/"金额总计"行
4. 6 仓数据纵向拼接
5. 输出到新文件
