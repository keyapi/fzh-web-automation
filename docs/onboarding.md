# 通途库存下载 — 操作指南

> 适用：非技术同事，零编程背景。你只需要对 Codex 说人话即可。

## 前置条件

- Codex 已安装（如果没有，先找 keyapi 帮你装）
- 一台能上网的电脑（Windows 10+ 或 Mac）

## 第一步：拿到项目（只做一次）

把项目 clone 到你的电脑，比如 `D:\Work\赛狐\` 目录下：

```bash
git clone https://gitee.com/keyapi/fzh-web-automation
```

## 第二步：Codex 添加项目（只做一次）

1. 打开 Codex
2. 左侧项目列表 → **添加项目** → 选择刚 clone 的 `fzh-web-automation` 文件夹
3. 切换到该项目

## 第三步：安装环境（只做一次）

在 Codex 对话框里输入：

> **帮我设置自动化环境**

Codex 会自动检测你的电脑缺少什么，然后给你安装命令。你只需要**复制粘贴**它给的命令到终端执行。

全程 5-10 分钟。装完后 Codex 会告诉你"环境就绪"。

## 第四步：首次导出（需要手动登录一次）

在 Codex 对话框里输入：

> **通途导出库存**

Codex 会：
1. 自动打开浏览器，跳转到通途登录页
2. **你需要手动输入账号密码登录**（跟平时登录通途 ERP 一样）
3. 登录成功后，Codex 自动依次导出 6 个仓库的库存
4. 等待几分钟，全部导出完成后 Codex 会告诉你结果

> ⚠️ 手动登录只需要这一次。浏览器会记住登录状态，以后不用再登。

## 第五步：以后每次使用

在 Codex 对话框里输入：

> **通途导出库存**

就行了。全自动：打开浏览器 → 自动登录 → 依次导出 6 个仓库 → 完成。

## 导出的文件在哪

| 文件夹 | 内容 |
|--------|------|
| `downloads/` | 6 个仓库的原始库存清单 |
| `output/` | 合并后的库存清单 + 生成的导入文件 |

> 这些文件就是 fzh-data 项目需要的数据源。把它们复制到 fzh-data 对应模块的 `数据源/` 文件夹下即可。

## 常用对话

| 你想做什么 | 对 Codex 说 |
|-----------|------------|
| 下载全部 6 仓库存 | **通途导出库存** |
| 只下载某个仓库 | **通途导出 CENTRADE 仓库** |
| 登录过期了，重新登 | **通途重新登录** |
| 查看有哪些仓库 | **通途有哪些仓库** |
| 环境出问题了 | **帮我检查自动化环境** |
| 合并已下载的库存 | **通途合并库存** |

## 常见问题

**Q: 浏览器打开了但是白屏？**
A: 通途服务器有时候慢，等 30 秒会自动刷出来。

**Q: 导出按钮点了没反应？**
A: 可能是登录过期了。对 Codex 说"通途重新登录"。

**Q: 下载的 Excel 在哪？**
A: 在项目文件夹里的 `downloads/`（原始）和 `output/`（处理后的）子目录下。

**Q: 怎么把文件给 fzh-data 用？**
A: 把 `output/` 里的 `通途合并库存结存清单*.xlsx` 复制到 fzh-data 项目的 `stock_init/数据源/` 或 `warehouse_restock/数据源/` 目录下。

**Q: Codex 说"找不到 uv"？**
A: 对 Codex 说"帮我设置自动化环境"，它会自动检测并安装。

**Q: 之前 clone 过了，怎么更新到最新版？**
A: 对 Codex 说 **"帮我更新项目"**，它会自动运行 git pull 拉取最新代码。

**Q: 安全库存/头程报关费会被覆盖吗？**
A: 不会。脚本生成导入文件时这两列留空，不会覆盖通途现有数据。
